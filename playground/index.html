Magnesium

Every element below is styled by CSS custom properties emitted through the API. The library ships no theme — these tokens are the playground's own.

@use "@magnesium/theme" with ($prefix: "ds")

emit()

emit($tokens, $namespace, $include, $exclude, $layer)

Turns a Sass map into custom property declarations. Nested maps flatten into hyphenated names, and null values are skipped entirely.

primary
surface-sunken
on-surface
muted
error
success
$colors: (
    "primary": #4f46e5,
    "error": #dc2626
);

:root {
    @include theme.emit($colors, "color");
}
:root {
    --ds-color-primary: #4f46e5;
    --ds-color-error: #dc2626;
}

variable()

variable($tokens, $token, $namespace, $fallback)

Returns a var() reference for one token. With $fallback: true the map value is inlined, so the component still renders if the property was never emitted. An unknown key raises an @error at compile time.

No :root declaration backs these buttons — the fallbacks carry them.

.button {
    background: theme.variable(
        $button, "container-color", "button", true
    );
}
.button {
    background: var(--ds-button-container-color, #4f46e5);
}

refs()

refs($tokens, $namespace)

Rewrites a whole map into var() references, recursing through nested maps. You keep the map shape and read it with map.get(), so a token is declared once and consumed everywhere. Here the fallbacks are themselves tokens, which is why the card follows the scheme without ever emitting --ds-card-*.

Design tokens

This card's background, border, radius and padding all come out of a single transformed map. 

$card: (
    "bg": theme.ref("color-surface-raised"),
    "radius": 14px
);

$refs: theme.refs($card, "card");

.card {
    background: map.get($refs, "bg");
    border-radius: map.get($refs, "radius");
}
.card {
    background: var(--ds-card-bg, var(--ds-color-surface-raised));
    border-radius: var(--ds-card-radius, 14px);
}

theme()

theme($refs, $tokens, $namespace, $include, $exclude, $layer)

Validates a token map against a reference schema, then emits it. Any key absent from the schema stops the build with an @error — a typo becomes a compile failure instead of a property that silently never applies.

Success Error Neutral

Same schema, three overrides — each one checked at compile time.

.badge {
    @include theme.theme($badge, (
        "bg-color": #16a34a
    ), "badge");
}
// "bg-colour" is not in the schema
@include theme.theme($badge, (
    "bg-colour": #16a34a
), "badge");

// Error: Unsupported token: 'bg-colour'.

scheme()

scheme($scheme, $selector, $layer)

Scopes declarations to a color scheme. Without $selector it wraps them in @media (prefers-color-scheme); with one, in that selector instead. The control in the header switches between both paths.

Autothe media query decides
Light / Darkthe selector overrides it
@include theme.scheme("dark") {
    :root { @include theme.emit($dark, "color"); }
}

@include theme.scheme($selector: "[data-theme='dark']") {
    @include theme.emit($dark, "color");
}
@media (prefers-color-scheme: dark) {
    :root { --ds-color-surface: #0e0f13; }
}

[data-theme="dark"] {
    --ds-color-surface: #0e0f13;
}

ref() & name()

ref($token) · name($name...)

The two prefix-aware primitives. ref() points at a token from another namespace without holding its map; name() just builds the hyphenated string. Neither hardcodes ds, so renaming the prefix stays a one-line change.

A link colored through ref(), with no access to the color map.

name("color", "primary") → 

.link {
    color: theme.ref("color-primary");
}

.token::after {
    content: "#{theme.name('color', 'primary')}";
}
.link {
    color: var(--ds-color-primary);
}

.token::after {
    content: "ds-color-primary";
}

$include · $exclude · $layer

shared by emit() and theme()

$include and $exclude filter which keys reach the output, so one map can serve several scopes. $layer wraps the result in a named cascade layer, which keeps token defaults beneath any unlayered override.

info
warn
danger
debug — excluded

The debug key exists in the map but never reached the CSS, so its swatch has nothing to paint with. 

:root {
    @include theme.emit(
        $status, "status", $exclude: ("debug")
    );

    @include theme.emit(
        ("accent": #db2777), "demo", $layer: "tokens"
    );
}
:root {
    --ds-status-info: #0284c7;
    --ds-status-warn: #d97706;
    --ds-status-danger: #dc2626;
}

@layer tokens {
    :root { --ds-demo-accent: #db2777; }
}
